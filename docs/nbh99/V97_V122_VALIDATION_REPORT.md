동일 변이 프로필이 train에 두 번 나타나는 경우, 라벨은 같은 암종이 아니라
`LGG ↔ GBMLGG`, `KIRC ↔ KIPAN`의 상보쌍을 이뤘다. 따라서 test 프로필이 train의
singleton 프로필과 정확히 같으면 train 라벨을 그대로 복사하는 것이 아니라, train에서
학습한 상보 라벨을 적용해야 한다는 가설이다.

이 가설은 리더보드 점수나 test 라벨을 사용하지 않고 train 구조만으로 만들었다.

## 통과 기준과 해석

v122는 다음 조건을 모두 만족할 때만 submission을 생성하도록 fail-closed로 구현했다.

1. 두 해상도 각각 상보 매핑 클래스가 정확히 4개일 것
2. train 상보쌍 그룹이 각 해상도에서 400개 이상일 것
3. 구조 검증 정확도와 매핑 purity가 모두 1.0일 것
4. 두 해상도 최종 예측의 불일치가 0건일 것
5. v97 대비 변경 수가 1~10건일 것
6. 기존 submission과 SHA256이 중복되지 않을 것

좋은 점은 v97의 2545개 예측을 그대로 보존하면서, 모델 확률과 독립적인 데이터 생성 구조
신호를 사용한다는 것이다. 개선할 점은 실제 변경이 한 건뿐이라 리더보드 상승 폭이 제한될
수 있다는 것이다. 실제 리더보드에서 `+0.0015168659` 상승해 가설의 외부 타당성도 확인됐다.
다만 변경이 한 건뿐이어서 0.5 돌파용 공격적 후보가 아니라, 강한 근거를 가진 저위험 단일
교정 전략이었다.
